### Highlight & Quick Start

- **Fleet Showcase & Pricing** — Katalog motor matic & adventure lengkap dengan tarif harian/mingguan/bulanan serta CTA booking WhatsApp langsung.
- **GSAP Scroll choreography & SEO OpenGraph** — Dioptimasi untuk preview media sosial & deployment statis Vercel (`vercel.json`).

```bash
npm install && npm run dev    # http://localhost:5173
npm run build
```
